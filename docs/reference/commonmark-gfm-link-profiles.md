# CommonMark and GFM Link Profiles

Linkity has two distinct Markdown profiles:

- `commonmark` implements CommonMark link forms: inline links, full/collapsed/shortcut reference links (resolved through `ParseContext.referenceDefinitions`), and angle-bracket URI/email autolinks.
- `gfm` composes that grammar with GFM's extended `www.`, HTTP(S), and email autolinks.

The grammar sources are `grammars/commonmark-link-rules.peggy` and
`grammars/gfm-link-extension.peggy`. The generator composes the CommonMark rules
into the GFM grammar, so GFM does not fork link rules. Generated parser code is
checked in under `src/syntaxes/generated/` and regenerated by `pnpm build`.

Fixtures cite the authoritative specifications:

- [CommonMark 0.31.2: inline links](https://spec.commonmark.org/0.31.2/#inline-link)
- [CommonMark 0.31.2: reference links](https://spec.commonmark.org/0.31.2/#reference-link)
- [CommonMark 0.31.2: autolinks](https://spec.commonmark.org/0.31.2/#autolinks)
- [GFM: autolinks extension](https://github.github.com/gfm/#autolinks-extension-)

`gfm` is deliberately an extension of `commonmark`; the profiles remain separate
because extended autolinks are not CommonMark syntax.
