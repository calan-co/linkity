# Explore Backlinks

Use the backlinks panel to see incoming and outgoing relationships.

## Steps

1. Open a Markdown file with wikilinks.
2. Open the backlinks panel from the Activity Bar.
3. Review:

   - Incoming links (files that link to the current file)
   - Outgoing links (files the current file links to)

4. Click any entry to navigate to its source.

## Tips

- Use the Rebuild Workspace Index command if the list looks stale.
- Link positions now reflect exact line and column offsets for quick jumps.
