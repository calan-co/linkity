# Work Item 5: Reference Generation (Manual & Auto)

## Goal

Implement reference link generation to convert wikilinks into standard markdown reference definitions, enabling GitHub/GFM compatibility (critical for Foam users).

## Tasks

- [ ] Implement ReferenceGenerator service
  - [ ] Scan document for all wikilinks  
  - [ ] Convert to markdown reference format: `[text]: /path`
  - [ ] Handle aliases: `[[file|Custom]]` → `[Custom]: /path`
  - [ ] Idempotent: update existing, don't duplicate
  - [ ] Mark auto-generated section with HTML comment
  - [ ] Preserve manually-edited descriptions
- [ ] Add "Generate References" command
- [ ] Implement auto-generation on save (configurable)
  - [ ] Hook onDidSaveTextDocument event
  - [ ] Check config: `wikilinks.autoGenerateReferences`
  - [ ] Generate references if enabled
  - [ ] Show notification on first auto-generation
- [ ] Add reference format options (markdown, inline)
- [ ] Create tests for idempotency

## Technical Details

### Reference Generation Example

```markdown
Input:
Check out [[Project Notes|the project]] and [[Meeting Notes]].

Output (appended):
<!-- wikilinks:references-start -->
[the project]: /path/to/Project%20Notes.md
[Meeting Notes]: /path/to/Meeting%20Notes.md
<!-- wikilinks:references-end -->
```

### ReferenceGenerator API

```typescript
export class ReferenceGenerator {
  async generateForDocument(document: TextDocument): Promise<TextEdit[]>
  async generateForWorkspace(): Promise<void>
  isAutoGenerated(text: string): boolean
  extractManualDescriptions(text: string): Map<string, string>
}
```

## Deliverables

1. ReferenceGenerator service with idempotent generation
2. Manual command: "Wikilinks: Generate References"
3. Auto-generation on save (configurable, OFF by default)
4. Preservation of manual edits
5. Tests for edge cases

## Acceptance Criteria

1. Generates references for all wikilinks in document
2. Uses alias as reference text when present
3. Idempotent: running twice produces same output
4. Preserves manually-added descriptions
5. Auto-generation respects config setting (default: OFF)
6. HTML comment markers clearly identify auto-generated content
7. Handles special characters in filenames (URL encoding)
8. Performance: <500ms for 100-link document
